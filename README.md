# Ebogo Tourisme — Site web V2

Site statique bilingue français/anglais pour l'Escale écotouristique d'Ebogo.

## Nouveautés V2

- Bandeau d'informations rapides : localisation, WhatsApp, email, publics visés.
- Section « Séjours conseillés » avec parcours prêts à réserver.
- Guide pratique pour préparer la visite.
- Recherche dans la grille tarifaire.
- Formulaire WhatsApp enrichi : date, nombre de visiteurs, activité, repas, langue du guide, message.
- Section carte / localisation.
- Galerie avec agrandissement des images.
- Boutons flottants Réserver / WhatsApp.
- Améliorations responsive mobile.

## Lancer en local

```bash
python3 -m http.server 5173
```

Puis ouvrir le port 5173 dans Codespaces.
